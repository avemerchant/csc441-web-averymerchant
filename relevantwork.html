Relevant Coursework

Here are some course I've taken at Le Moyne.

Computer Science Courses

Web and Mobile Secure Software

This course focused on the development of secure web and mobile applications, emphasizing best practices in security and privacy.

Data Structures

This course covered fundamental data structures such as arrays, linked lists, stacks, queues, trees, and graphs, along with their algorithms and applications.

Object-Oriented Software Design

This course explored object-oriented programming principles, design patterns, and software architecture to create maintainable and scalable software systems.

Distributed Systems

This course delved into the design and implementation of distributed systems, including topics like concurrency, fault tolerance, and communication protocols.

Discrete Mathematics

This course introduced mathematical reasoning and techniques essential for computer science, including logic, set theory, combinatorics, and graph theory.

Numerical Methods

This course focused on numerical analysis techniques for solving mathematical problems computationally, including root finding, interpolation, and numerical integration.

Statistics Courses

While my primary area of study is Computer Science, I also picked up a minor in Applied Statistics.

Data Science

This course introduced the principles and techniques of data science, including data manipulation, visualization, and statistical modeling.

Advanced Statistical Methods

This course covered advanced statistical techniques for analyzing complex data sets, including regression analysis, multivariate analysis, and hypothesis testing.

Statistical Consulting

This course provided practical experience in applying statistical methods to real-world problems, emphasizing communication and collaboration with clients.
